# Ship Street Ventures website

Static one-page site for Ship Street Ventures, hosted on GitHub Pages.

- `index.html`: page content and copy
- `assets/style.css`: layout and tokens from the Ship Street Ventures design system
- `assets/field.js`: the interactive pixel fields (cursor paint, press-and-hold burst, idle word, A/B process toys, service row traces, headline decode)

No build step. Edit the files and push to `main`; Pages redeploys in about a minute.

To use the custom domain later, add a `CNAME` file containing `shipstreet.ventures` and point DNS at GitHub Pages.
